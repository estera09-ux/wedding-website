# Emma & Liam – Wedding Website

A responsive wedding website for a fictional couple, built with HTML, CSS and JavaScript.

**Live demo:** https://estera09-ux.github.io/wedding-website/

## Features
- Hero section with the couple's names, date and location
- Live countdown to the wedding day
- "Moments Together" photo gallery
- Wedding schedule for the ceremony and reception
- Venue section with an embedded Google Map

## Built with
- HTML
- CSS
- JavaScript
